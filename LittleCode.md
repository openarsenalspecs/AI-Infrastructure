# LittleCode

**The little AI that codes big.**

LittleCode is an open-source AI-powered design canvas that transforms natural language prompts into **production-ready front-end code**. Users of any age can see their design concepts come to life using **text, voice, or visual prompts**. LittleCode supports multiple frameworks, real-time previews, advanced AI-driven design intelligence, and futuristic experimental features.

---

## 🚀 Key Features

- Text, voice, and cross-modal input (sketches, screenshots, videos)  
- Full front-end project generation (HTML, CSS, JS, React, Vue, Angular)  
- Real-time preview and dynamic data binding  
- Multi-user collaboration, version control, and community templates  
- AI-powered accessibility, UX, and performance optimization  
- Export to desktop, mobile, web, and experimental VR/AR  
- Futuristic experimental features, including sentient AI interaction and IoT integration

## ⚡ Getting Started

### Prerequisites
- Node.js v18+  
- npm or yarn  
- Git for repository cloning  

### Installation
```bash
git clone https://gitlab.com/Roxanne_Ardary/littlecode.git
cd littlecode
npm install
```
### Running LittleCode
```bash
npm start
```
This will launch a local development server with the live AI design canvas.

### Building for Production
```bash
npm run build
```
Outputs production-ready project files.
